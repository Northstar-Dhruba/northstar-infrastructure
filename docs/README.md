# Infrastructure Layer Documentation

This directory contains specifications and technical adapter documentation for the Infrastructure Layer.

## Key Reference Specifications

- **Architecture Handbook v2.0:** Defines the complete platform architecture, dependency rules, and frozen boundaries.
- **Application Layer Design Specification v1.0:** Defines outbound port contracts that Infrastructure adapters implement.
- **Northstar Architecture v2.0:** Defines the Infrastructure model, adapter responsibilities, and dependency inversion rules.
